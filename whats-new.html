1.1 · 20 October 2026

  • Convert Wiki-Links. Project ▸ Convert Wiki-Links rewrites every [[wiki-link]] in a project as a standard Markdown link, for notes brought from Obsidian: aliases, headings and embedded pictures are kept, links to notes that aren’t there can point to new notes made when followed, and the whole conversion can be undone. See Links and Backlinks and Support.
  • Writing Replay (experimental). A record of how a note is written, played back and exportable as a web page, with trusted timestamps. Off until turned on in Settings ▸ General. See Writing Replay.
  • New Note with Questions. File ▸ New Note with Questions has the AI model write Socratic questions about a subject you give, as the headings of a new note for you to answer in your own words. See Ask Your Notes and AI.
  • Ask a Follow-up Question. Edit ▸ Ask a Follow-up Question (⌥⌘/) has the model read the passage you’re writing and ask one question back, in the margin; add it as a heading or dismiss it.
  • Links to notes that don’t exist yet make them when followed, titled from the name, as wiki-links do.
  • Export as Word Document (⇧⌘E): the open note as a .docx with Word’s own styles, pictures embedded and links that work.
  • Markdown files on your Mac: Quick Look (Space in Finder) shows them in Grasmere’s style, and Grasmere can be the app that opens them (Settings ▸ General ▸ Markdown files), opening each note in its project, or on its own in a window of its own, with its links working.
  • Shortcuts as other writing apps have them: ⌘O opens a note by name (⌥⌘O for a file), ⌘P exports the page as a PDF, ⌥⌘1–3 make a heading and ⌥⌘Q a blockquote (several lines pasted into a quote are all quoted).
  • Standard buttons on the sheets, in the theme’s colours, and no trailing ellipses on menu items. The margin’s History section is called Git History. Lines are set at each font’s own height, with no spacing added by the app, so an empty line is as tall as a typed one and typing on it no longer moves the page.
