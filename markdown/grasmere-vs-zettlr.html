Grasmere vs Zettlr

Zettlr and Grasmere are the two Markdown editors on this site’s list of Scrivener alternatives that have citations built in, so they’re the pair academics compare. Zettlr is free and open source, runs everywhere, and stands on Pandoc. Grasmere is a paid Mac app that does the same jobs without Pandoc and adds a few of its own. Grasmere is ours.

In a sentence each

Zettlr is a free, open-source Markdown editor for Mac, Windows and Linux, made with academics in mind, with Pandoc citations from a CSL JSON or BibTeX library and export through an embedded Pandoc. Grasmere is a Mac app for long writing in Markdown files, with sources by DOI and ISBN, citations in four styles, a Word review round trip and a Publish stage.

Where Zettlr is better

  • Any citation style. If your journal has a CSL file, or you need Vancouver, IEEE, OSCOLA or Chicago notes, Zettlr writes it. Grasmere writes four author-date styles.
  • Free, open, everywhere. The source is public, it costs nothing, and it runs on Windows and Linux.
  • Pandoc underneath. Anything Pandoc can export, Zettlr can, and your citations are in Pandoc’s syntax, which other tools read.
  • Zettelkasten. IDs and links for a card index of notes.

Where Grasmere is better

  • No library to maintain. A source is made from a DOI, and the reference details live in a Markdown file beside your chapters, not in a .bib file kept in step by another app.
  • Review. Zettlr imports a Word file with one blanket choice for its comments. Grasmere shows each tracked change and comment where it belongs and lets you accept or reject it.
  • Publishing without LaTeX. A folder of chapters becomes a manuscript-format or book PDF, or one Word document, with nothing installed.
  • Sources in the app. Save a web page or drop a PDF, read it beside the draft, highlight, and quote with the citation attached.

Moving across

Zettlr’s files are Markdown, so open the folder. Import your .bib or CSL JSON with Project ▸ Import Sources, then Project ▸ Convert Pandoc Citations turns each [@key] into a link to the matching source. Going the other way, each source’s front matter holds the reference fields, and in 1.6 the Publish stage writes a .bib alongside LaTeX.

Which to choose

Choose Zettlr if you need a style Grasmere doesn’t write, work on Windows or Linux, or want open-source software and are at home with Pandoc and LaTeX. Choose Grasmere if you write APA, Harvard, Chicago author-date or MLA on a Mac, send drafts to people who use Word, and would rather not run a toolchain.
