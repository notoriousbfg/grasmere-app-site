Themes and Settings

Grasmere is meant to be calm to read and write in, with a readable column of text in good type and your document’s structure shown quietly. This guide covers how the page looks, and lists every setting in one place. To open Settings, choose it from the Grasmere menu or press ⌘,.

Themes

There are eight themes, each with its own type:

ThemeLight or darkType
PaperLightSerif: cream paper and coloured inks
MonoLightMonospace: black on white, ruled and square
EndingLightIBM Plex Sans, with Plex Mono for code and labels: white, faint greys and blues, a vivid blue accent
SlateDarkSerif: blue-grey
GraphiteDarkSans-serif: neutral grey, with quiet steel inks
SootDarkMonospace: warm black and army green
LamplightDarkSerif: a dark room, a lit page, gold ink
Ending DarkDarkIBM Plex Sans, with Plex Mono for code and labels: grey-blues on navy, a crimson accent

New in 1.6. Ending and Ending Dark are new. Native, Native Dark, Wallace, Wallace Dark and An Old Hope have gone; a theme file of your own can make a look like any of them (see Your own themes, below).

To have Grasmere go light and dark with your Mac, turn on Match the Mac’s light or dark mode in Settings ▸ Appearance and choose a light theme and a dark one. Turn it off to keep one theme all the time, whatever your Mac is doing. The whole app follows the theme, menus and panels included.

Your own themes

New in 1.6. A theme can be a file you write. In Settings ▸ Appearance ▸ Your own themes, click Choose Folder and pick the folder your themes will live in (the panel opens on .grasmere/themes in your home folder; any folder will do). Every .json file in it is a theme, listed with the others in the theme pickers under the name you give it.

{
  "from": "paper",
  "name": "Dusk",
  "blurb": "Paper, with a plum accent",
  "accent": "#7A3B69",
  "link": "#7A3B69",
  "look.radius": 4
}
  • from names the theme the file starts from: paper, mono, ending, slate, graphite, soot, lamplight or endingDark. Without it the file starts from Paper, or from Slate when it says "isDark": true.
  • name and blurb are what the picker shows.
  • Every other key is one quality of the theme, by name: a colour as #RRGGBB, a number, or true or false. The file only needs the ones that differ.
  • family chooses the type: serif, sans, mono or plex.

To see every quality’s name, type a name beside New theme file and click Make. Grasmere writes the theme on screen out whole, with every quality in it, and shows the file in the Finder for you to edit. Save the file and the window changes at once, so you can work on a theme with Grasmere open beside your editor.

A file that can’t be read, or a key Grasmere doesn’t know, is named in red under the folder’s line in Settings, as in “Dusk.json: not taken: look.nothing”. If a theme you’d chosen goes missing, Grasmere falls back to its usual theme. Forget stops reading the folder; the files stay where they are.

Text size and width

  • Text size is in Settings ▸ Appearance. You can also press ⌘+ and ⌘− to change it, and ⌘0 to go back to the usual size (17 pt).
  • Text width is Narrow, Medium, Wide or Full window.

When you change the size or width, the line you were reading stays where it is.

Every setting

General

  • Save automatically: see Saving, Safety and Git.
  • Date order: Automatic, Day first, Month first or Year first. It’s used for journal entry titles, the dates written into insights and due dates in the Tasks list.
  • Save in these folders: Pictures and videos (media by default). Insights go in the research folder (new in 1.4; a project with an insights folder from before keeps it as it is).
  • Journal: Folder, Template and File names. See Journal.
  • Research: where Project ▸ Save Web Page, the Share menu and New Document from Clipboard save web pages (research by default; a project’s Research folder from before is used as it is). See Research.

New in 1.4. The three folder fields, Pictures and videos, the journal’s Folder and the research Folder, belong to the project in front, and the section headers name it. The field shows the folder as the project has it, so a research folder renamed sources in the contents reads sources here. Type a new name and press Return, or click away, and the folder is renamed on disk, or moved if you type a path like notes/diary, with links following and Undo at the foot of the window. A folder that hasn’t been made yet is just named, and made when first needed. A name outside the project, or a hidden one, is refused. With no project open, the fields are what new projects start with. See The Contents.

  • Markdown files: which app opens .md files when you double-click them, with a button to make it Grasmere. See The Contents.
  • Show images from the web.
  • Spelling: Check spelling while typing, and the language.
  • Markdown problems: Check the Markdown as you write. New in 1.4: on to begin with; if you’d turned it off, it stays off. See The Margin.
  • Writing replay (experimental): Allow recording how documents are written, and the timestamp service. See Writing Replay.

Appearance

  • Themes, text size and text width, as above.
  • Your own themes and New theme file (new in 1.6), as above.
  • Show word count beneath the page.
  • In focus mode: Keep the current line in the middle of the window, and Fade all but the current paragraph. See Focus Mode and Split View.
  • Name documents in the sidebar by, Show images in the contents, Show project.md in the contents, Show index.md in the contents, Show research.md in the contents and Manuscripts and Show highlights.md in the contents and Manuscripts (new in 1.4, off by default; the Research stage shows and opens the highlights book itself). See The Contents, Citations and Research.

Automation

These settings belong to the open project.

  • Git: commit changes after saving, and push after committing.
  • Commits: the name and email to use when the repository doesn’t set its own.
  • Run a shortcut when a document is saved, created, renamed or moved, or the project is opened.
  • Publish with: the Shortcut Project ▸ Publish runs, whether to build the website first, and whether to include linked files and the research folder (saved web pages and insights).

See Saving, Safety and Git and Publishing.

Accessibility

Grasmere works with VoiceOver, and respects Reduce Motion and Increase Contrast in System Settings ▸ Accessibility.
