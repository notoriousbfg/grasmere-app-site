Themes and Settings

Grasmere is meant to be calm to read and write in: a readable column of text, set in good type, with your notes’ structure shown quietly. This guide covers the look of the page and gathers every setting in one place. Open Settings from the Grasmere menu, or press ⌘,.

Themes

There are four themes, each with its own type:

ThemeLight or darkType
PaperLightSerif: cream paper and coloured inks
SlateDarkSerif: blue-grey
GraphiteDarkSans-serif: neutral grey
SootDarkMonospace: Paper’s inks by lamplight

In Settings ▸ Appearance, Match the Mac’s light or dark mode switches between a light theme and a dark theme with your Mac, and you choose one of each. Turn it off to use one theme all the time, whatever your Mac is doing. The whole app, its menus and panels too, follows the theme.

Text size and width

  • Text size in Settings ▸ Appearance, or ⌘+ and ⌘− to change it and ⌘0 to go back to the usual size (17 pt).
  • Text width: Narrow, Medium, Wide or Full window.

The line you were reading stays in place as the size or width changes.

Every setting

General

  • Save automatically: see Saving, Safety and Git.
  • Date order: Automatic, Day first, Month first or Year first, for the titles of daily notes, the dates written into clippings and insights, and due dates in the Tasks list.
  • Save in these folders: Pictures and videos, Web clippings and Insights.
  • Daily notes: Folder, Template and File names. See Daily Notes.
  • Show images from the web and Offer to save what you copy.
  • Spelling: Check spelling while typing, and the language.

Appearance

  • Themes, text size and text width, as above.
  • Show word count beneath the page.
  • In focus mode: Keep the current line in the middle of the window, and Fade all but the current paragraph. See Focus Mode and Split View.
  • Name notes in the sidebar by, Show images in the contents, Show project.md in the contents and Show index.md in the contents. See The Contents.

Links

  • Update links automatically when notes move, and when to ask first.
  • Shorten link addresses.
  • Turn pasted web addresses into titled links.

See Links and Backlinks.

Capture

  • Show in menu bar, Open at login, the keyboard shortcut, and which project captures go to. See Quick Capture and Sharing.

AI

  • Provider and API keys, and how much Copy as Context copies. See Ask Your Notes and AI.

Automation

These settings belong to the open project.

  • Git: commit changes after saving, and push after committing.
  • Commits: the name and email to use when the repository doesn’t set its own.
  • Run a shortcut when… a note is saved, created, renamed or moved, or the project is opened.
  • Publish with: the Shortcut Project ▸ Publish runs, whether to build the website first, and whether to include linked files, web clippings and saved insights.

See Saving, Safety and Git and Publishing.

Accessibility

Grasmere works with VoiceOver, and respects Reduce Motion and Increase Contrast in System Settings ▸ Accessibility.
