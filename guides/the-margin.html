The Margin

The margin on the right shows how the open document connects to the rest of your project. View ▸ Show Margin (⌃⌥⌘S), or the button at the right of the running head, shows or hides it. Drag its edge to make it wider or narrower.

The margin has three tabs: Page (the document you’re on), Tasks (⇧⌘T) and Ask (⇧⌘A). This guide is about the Page tab; see Tasks and Due Dates and Ask Your Documents and AI for the others.

Click a section’s heading to close or open it; Grasmere remembers which you keep open. A section with nothing in it (Mentioned in, Front Matter, Git History or Problems) stays closed and says None (Problems says No problems); click it to look, and it opens by itself once there’s something to show.

New in 1.3: while a review is in hand, a Review section comes first, with the reviewers’ comments and changes (see Review). A document in the research folder says at the top whether it’s a source, such as “A source · Book”, or a research note you can make into one (see Citations).

Linked from

Every document that links to the open document, each as a numbered sidenote with the line that does it. Click a sidenote to open that document at the link.

If another document links to a passage in this one, a small number beside the passage matches its sidenote. Point at the number to see the passage highlighted; point at the sidenote to see which passage it quotes.

Links to

The documents the open document links to, with the folder each is in.

Mentioned in

Documents that name the open document, by its title, without linking to it. The words are highlighted. Click one to open the document at the mention, or click Link to turn the mention into an ordinary link, with Undo.

If a document goes by other names, list them in its front matter and those are found too:

---
aliases: [Peggy, Mrs Hill]
---

Very short names, dates and mentions inside headings, code and existing links are left out.

Front Matter

New in 1.3. The fields at the top of the document, between its --- lines, as rows: the key, and its value in a field you can edit in place. Press Return, or click elsewhere, and the line in the document changes to match; Escape puts the old value back. The × that appears beside a row removes the field; Add a field at the bottom takes a key and a value and writes them as the last line of the block. A document with no front matter shows the section closed, saying None; open it, and the first field you add makes the --- block at the top. Each change is one step in Undo (⌘Z), and typing in the block on the page updates the rows a moment later.

Values are shown as written: strings without their quotes, numbers, true/false and dates as they are. A list (tags: [a, b], or - item lines under the key) is one row with its items separated by commas, and goes back in the form it had. A nested value (author: with name: and role: under it) is shown but edited in the text. A value is quoted only when YAML needs it: one with a colon, a leading # or [, or, for a field that holds words, one that would otherwise read as a number or a date. The other lines of the block are never touched. Front Matter is closed until you open it.

Git History

If your project folder is a git repository, Git History lists the commits that changed the open document, following it through renames. Choose one to see that version and what has changed since, then Restore This Version to bring it back as a single step you can undo, or Copy it. Git History is closed until you open it.

See Saving, Safety and Git for committing automatically.

Problems

New in 1.3. With Settings ▸ General ▸ Check the Markdown as you write on, the Page tab ends with a Problems section: what’s wrong with the open document’s Markdown, a line each, in plain words that say what to do. A red cross is an error (the Markdown won’t read as meant); an amber triangle is a warning (it reads, but not as well as it could). The header says how many there are, or No problems. Click a problem to put the cursor on its line. The document is checked about half a second after you stop typing, and nothing is ever changed for you.

The check is off until you turn it on, looks only at the open document, and never at anything inside a code block, front matter or an HTML comment. Broken links are judged the same way as the dotted underlines on the page and the sidebar’s Broken Links, so the three always agree. The rules:

RuleKindWhat it catches
fence.unclosedErrorA code fence (``` or ~~~) that is never closed, so the rest of the document is code
link.missingErrorA link to a document, file, heading or passage that isn’t in the project
image.missingErrorA picture whose file isn’t in the project
image.notImageErrorA picture link (![…](…)) to a file that isn’t a picture
frontMatter.unclosedErrorFront matter that opens with --- and never closes
frontMatter.malformedErrorA front matter line that isn’t name: value, a - item or a comment, or has unclosed quotes
table.cellsErrorA table row, or its separator line, with a different number of cells from the header
reference.undefinedErrorA reference link ([text][label]) whose [label]: address line is missing
footnote.undefinedErrorA footnote ([^1]) that is referred to but never written out
footnote.unusedErrorA footnote ([^1]: …) that nothing refers to
heading.jumpWarningA heading more than one level below the one before (# then ###)
heading.multipleWarningMore than one # title
heading.duplicateWarningTwo headings with the same text, so links to them are ambiguous
heading.noSpaceWarningA # with no space after it, which isn’t a heading
link.emptyWarningA link with no address ([text]() or []())
image.noAltWarningA picture with no alt text
url.bareWarningA web address written out, not as a link
emphasis.unbalancedWarningA *, ** or _ opened on a line and not closed on it
task.malformedWarningA task box written wrong ([x ], [ X], [] or -[ ]), which won’t tick
list.mixedMarkersWarningA list that changes bullet (-, * or +), which starts a new list
whitespace.trailingWarningA single space, or a tab, at the end of a line (two spaces make a line break; one does nothing)
fence.nestedWarningA code fence opened inside another with the same marker, which is read as code
citation.notSourceWarningA citation ([Field 2026](…)) to a document that isn't a source (its front matter has no type), so it won't be formatted on export

When the window is narrow

When there isn’t room for the contents, the page and the margin side by side, the margin hides first. Show it again and it floats over the page. Focus mode hides it too.
