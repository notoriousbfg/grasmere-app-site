Shortcuts and the Command Line

New in 1.3. Grasmere’s everyday work is offered to the Shortcuts app as actions: open a document, make one, add to today’s entry, search, check the Markdown and the links, export a PDF or Word document, compile a folder, publish the website. Each is a building block for your own shortcuts, and because the shortcuts command in Terminal runs a shortcut, each is also a command: shortcuts run sends the work to the running app, which does it with the folder access it already has, and prints the result.

In Shortcuts

Open the Shortcuts app, make a new shortcut, and search the actions for Grasmere: they are listed together in the app’s own category. Ten of them are also in Spotlight and Siri, as “Open a document in Grasmere”, “Append to today’s entry in Grasmere”, “Search Grasmere”, “Check Markdown in Grasmere”, and so on.

Every action works on the project in the front window. The ones that take a document or a folder also take a path to any project Grasmere has opened before (it keeps permission to those folders), so a shortcut can work on a project that isn’t open. A folder Grasmere has never opened gives an error that names it: open it once (File ▸ Open Folder), and from then on it’s reachable.

Where an action takes a document, there are two fields: Document, for a file from another action or from the shortcut’s input, and Path, for a path typed in, or a document’s name or path in the front project (Low Water finds chapters/Low Water.md). Leave both empty for the document open on the page. Where an action takes a project, give the folder’s path or a recent project’s name, or leave it empty for the front window’s.

Results are plain values, so they chain: a path or a line of text, a file, or a list of lines (one per document, or one per problem).

From the command line

The shortcuts command (man shortcuts) runs a shortcut by name: shortcuts run "<shortcut>". It runs a shortcut, not an action, so for each action you want from Terminal, make a shortcut of one step, once, in the Shortcuts app: add the Grasmere action, and name the shortcut after it (“Check Markdown”, say). From then on it’s a command.

The shortcut’s input comes from -i (--input-path): a file’s path, or - for what’s piped in. Its result is printed with -o - (--output-path), or written to a file with -o <path>; leave -o out and the result goes nowhere. So in the one-step shortcut, put Shortcut Input in the action’s field: in the Document field when you’ll give a file with -i <path>, or in the Text, Path or Query field when you’ll pipe text in with -i -. (A file piped to a text field arrives as its contents, not its path, so a path typed at the prompt goes in through the pipe.)

# Add a thought to today's entry in the front project
echo "a thought" | shortcuts run "Append to Today's Entry" -i - -o -

# Check a document's Markdown (Shortcut Input in the Document field)
shortcuts run "Check Markdown" -i ~/Notes/post.md -o -

# Search, a line per document
echo ferry | shortcuts run "Search Documents" -i - -o - | head

# Publish the front project's website, or a project by its folder
shortcuts run "Publish Website" -o -
echo ~/Notes | shortcuts run "Publish Website" -i - -o -

# Export a PDF next to the document (the Output field left empty)
shortcuts run "Export PDF" -i ~/Notes/post.md

# The list of broken links, in the front project
shortcuts run "Check Links" -o -

A small function makes this read like a command:

grasmere() { local name=$1; shift; printf '%s' "$*" | shortcuts run "$name" -i - -o -; }

grasmere "Append to Today's Entry" bread rose well today
grasmere "Open Document" "chapters/Low Water.md"
grasmere "Get Document Text" Revisions | wc -w

Two things to know:

  • An action that returns a file (New Document, Append to Today’s Entry, Append to Document, the exports, Compile Folder) gives -o - the file’s contents: a new document’s text, or a PDF’s bytes. For a document that’s what you want; for an export, use the action’s Output field to say where the file goes and leave -o out, or write it with -o out.pdf.
  • A shortcut can run only while Grasmere is running or can be launched; shortcuts run opens it if need be. Publish Website and Compile Folder take as long as they take; the command waits, and the app stays usable meanwhile.
