Daily Notes

A daily note is a place to write without deciding where: what you did, what you read, what you’re thinking about. Grasmere keeps one note for each day, in a folder of their own.

Today’s note (⌘T)

Go ▸ Today (⌘T), or the calendar button above the contents, opens today’s note, making it if it isn’t there yet. It’s called something like journal/2026-10-11.md and titled like a diary: “Sunday 11th October”.

A note that’s already there is never written over, so ⌘T is always safe to press.

Stepping between days

Go ▸ Previous Day (⌥⌘←) and Next Day (⌥⌘→) step between the days that have notes, skipping the days that don’t. From a daily note, they step through the folder that note is in. From any other note, they start from today in the daily notes folder.

Templates

A template is an ordinary note in your project whose text starts each new day’s note. Give its path in Settings ▸ General ▸ Daily notes ▸ Template, such as templates/Daily.md.

  • The template’s own first heading is left out; the new note gets the day’s title instead.
  • {{date}} becomes the day’s date, as 2026-10-11, and {{title}} the day’s title.
  • Links in the template are adjusted so they still work from the journal folder.

For example, a template like this:

## Plan

- [ ] 

## Notes

Written on {{date}}.

File names and titles

In Settings ▸ General ▸ Daily notes:

  • Folder sets where daily notes go (journal by default).
  • File names chooses how new notes are named: 2026-10-11 (year first, the default, which sorts by date everywhere), 11-10-2026 (day first) or 10-11-2026 (month first). Day first and month first are there for notes brought from another app.

Grasmere finds a day’s note under any of the three names, so changing the setting never makes a second note for the same day.

Settings ▸ General ▸ Date order (Automatic, Day first, Month first or Year first) sets how the titles of new daily notes are written, such as “Friday 9th October” or “Friday, October 9”. Automatic follows your Mac’s region. Existing notes keep their titles.

Quick capture

You can add a line to today’s note from any app without switching to Grasmere: press ⌃⌥⌘N or click the book in the menu bar. See Quick Capture and Sharing.
