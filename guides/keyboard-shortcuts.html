Keyboard Shortcuts

Here’s every keyboard shortcut in Grasmere, menu by menu. ⌘ is Command, ⌥ is Option, ⌃ is Control and ⇧ is Shift.

From 1.1: a few shortcuts changed to match Obsidian, Ulysses and iA Writer. Open Quickly is now ⌘O (it was ⌘P), Open File is ⌥⌘O (it was ⌘O) and Export as PDF is ⌘P (it was ⇧⌘E). Headings got ⌥⌘1–3.

New in 1.4: Export is a submenu, File ▸ Export ▸ PDF (⌘P), Word Document (⇧⌘E) and Anki Deck. In a project, ⌘P and ⇧⌘E put the open document in hand and open the Publish stage, where you publish it; a document on its own still gets the save panel. The four stages are ⌃1 to ⌃4, the Review screen is ⇧⌘R and a comment of your own is ⌥⌘A.
