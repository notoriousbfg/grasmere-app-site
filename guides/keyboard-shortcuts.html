Keyboard Shortcuts

Here’s every keyboard shortcut in Grasmere, menu by menu. ⌘ is Command, ⌥ is Option, ⌃ is Control and ⇧ is Shift.

From 1.1: a few shortcuts changed to match Obsidian, Ulysses and iA Writer. Open Quickly is now ⌘O (it was ⌘P), Open File is ⌥⌘O (it was ⌘O) and Export as PDF is ⌘P (it was ⇧⌘E). Headings got ⌥⌘1–3.

While writing

KeysWhat they do
ReturnOn a list item, start the next item; on an empty item, end the list
Tab, ⇧TabNest a list item, or bring it back out; in a table, move between cells
[text](Open the link picker
# in the link pickerChoose one of the document’s headings
[@Open the citation picker

With the mouse

ActionWhat it does
⌘-click a linkFollow it straight away
⌥-click a link, document, search result or taskOpen it in split view
⌘-click or ⇧-click in the contentsPick several documents
Double-click a document in the contentsRename it
