Keyboard Shortcuts

Every keyboard shortcut in Grasmere, by menu. ⌘ is Command, ⌥ Option, ⌃ Control and ⇧ Shift.

While writing

KeysWhat they do
ReturnOn a list item, start the next item; on an empty item, end the list
Tab, ⇧TabNest a list item, or bring it back out; in a table, move between cells
[text](Open the link picker
# in the link pickerChoose one of the note’s headings

With the mouse

ActionWhat it does
⌘-click a linkFollow it straight away
⌥-click a link, note, search result or taskOpen it in split view
⌘-click or ⇧-click in the contentsPick several notes
Double-click a note in the contentsRename it

In the contents

KeysWhat they do
↑ ↓Move through the list
→ ←Open or close a folder
ReturnOpen the note
⌘⌫Move to Trash
Tab or escBack to the note

In the Index

KeysWhat they do
↑ ↓Through the deck
← →Along the links of the card in front
ReturnOpen the card in front
Type a titleJump to it
escBack to the note
