Writing and Formatting

Grasmere writes plain Markdown. What you type is what’s saved: the page styles headings, emphasis, lists and links as you write, and leaves the markup visible but faint, so you can always see and edit it.

Plain files

Every document is a .md file in the folder you opened. The first heading is the document’s title, and that’s what the contents list shows. There’s no database and no special syntax, so you can open the same files in any other editor, read them on GitHub, keep them in git, or hand them to an AI tool.

Front matter (a block between --- lines at the very top of a document) is kept as it is and shown faintly. Its fields can be edited in the margin’s Front Matter section too: see The Margin.

A code block (lines between ``` fences) is set in a monospaced type, with the fences faint. Name the language after the opening fence (```swift, ```python, ```json, ```sh, and so on) and the block’s keywords, strings, comments, numbers and types take quiet colours from the theme, as they do in the PDFs and websites you make from it. The text stays exactly as you typed it; a block with no language is left in the code colour alone. New in 1.3.

Formatting

ToDo this
Make text boldFormat ▸ Bold (⌘B), or type **bold**
Make text italicFormat ▸ Italic (⌘I), or type *italic*
Mark codeFormat ▸ Code, or type backticks
Add a headingFormat ▸ Heading 1, 2 or 3 (⌥⌘1, ⌥⌘2, ⌥⌘3), or start the line with #, ## or ###
QuoteFormat ▸ Blockquote (⌥⌘Q), or start the line with >. Return continues the quote (twice to end it), and several lines pasted into a quote are all quoted
Add a ruleType --- on a line of its own

Brackets, quotes and backticks come in pairs as you type them.

Lists

Lists carry on by themselves:

  • Return on a list line starts the next item.
  • Tab nests an item; ⇧Tab brings it back out.
  • Return on an empty item ends the list.
  • Numbered lists renumber themselves as you add and remove items.

A list item that starts with [ ] is a task. See Tasks and Due Dates.

Folding headings

Any heading can fold its section away, to give you a short outline of a long document. Point at a heading and click the chevron in the left margin, or use:

  • View ▸ Fold Section (⌥⌘[) and Unfold Section (⌥⌘])
  • View ▸ Fold All (⇧⌥⌘[) and Unfold All (⇧⌥⌘])

Folding only hides text on screen; the file never changes. Folds are remembered when you quit and reopen.

Dates

A date written as 2026-10-03 anywhere in your writing is shown as a quiet chip. Click it to choose another day from a calendar; only the date changes. Dates in code or in a link’s address are left alone.

Word count

The bar beneath the page shows the document’s words, links and backlinks. Select some text and it shows how many of the words you’ve selected. View ▸ Show Word Count, or Settings ▸ Appearance ▸ Show word count beneath the page, turns the bar on or off.

Spelling

Settings ▸ General ▸ Check spelling while typing turns the underline on or off. With the language set to Automatic, Grasmere works out the language of each paragraph as you write. Link addresses, code and front matter are never checked.

Undo

⌘Z undoes your typing, and the history survives saving. Things Grasmere does for you, such as rewriting links after a rename, can be undone too: see Links and Backlinks.
